# 산업연관표 분석 웹앱 — 교수님 Sample_IO 기반 기능 추가

원본: https://github.com/profguclass/Sample_IO

교수님 예시의 **원자료 탐색 / 380개 산업 최종수요 시뮬레이션 / Python(Pyodide) / 계수 검증** 기능을 유지했습니다.

## 추가한 기능 (2가지)

1. **산업별 투자 효율성 비교**: 산업 3개 선택, 각 산업의 최종수요 증가액을 0~10,000억원 슬라이더로 조절, 생산유발액·부가가치유발액·수입유발액 그래프 즉시 갱신, 유발배수 비교표.
2. **전방·후방 연관효과**: 산업별 영향력계수(생산유발계수행렬 열합/평균)와 감응도계수(행합/평균), 국산투입계수행렬의 후방(열)·전방(행) 직접 연결 산업 상위 10개, 수요 증가액에 따른 생산유발액 상위 12개 실시간 그래프.

### 계산 방식

- 교수님 `model.py`의 2023년 380개 기본부문 Excel 자료와 `L`, `M`, `V`, `ad` 행렬을 그대로 활용합니다.
- 산업 j의 수요 증가액 `f_j`에 대해 총 생산유발액 `sum_i L[i,j] * f_j`, 부가가치유발액 `sum_i V[i,j] * f_j`, 수입유발액 `sum_i M[i,j] * f_j`.
- 후방 영향력계수 `sum_i L[i,j] / (n * mean(L))`, 전방 감응도계수 `sum_j L[i,j] / (n * mean(L))`.
- 직접 연결 산업은 `ad[i,j]` (후방) 및 `ad[j,i]` (전방)로 표시. 전방 연결은 직접투입 관계이며 감응도계수와 다른 개념입니다.
- 수요 증가액을 조절해도 **계수 자체는 변하지 않습니다**. 생산유발액만 선형으로 달라집니다.
- 슬라이더 조작은 Python 계산 없이 미리 계산된 계수를 JavaScript에서 곱하여 실시간 반영합니다.
- 사용자가 입력하는 금액은 실제 금융투자액이 아니라 **국내 생산물 최종수요 증가액**을 의미합니다. 결과는 인과적 정책효과나 실제 투자수익률이 아닙니다.

## 배포

1. 이 ZIP의 최상위 파일 전체를 GitHub의 새 **Public** 저장소 최상위에 업로드합니다. 특히 `data/io-2023.xlsx` 파일이 반드시 있어야 합니다.
2. `Settings > Pages > Build and deployment`에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
3. 배포 URL에 접속해 **기본부문 불러오기** 버튼을 누릅니다. 최초 실행 시 Pyodide/NumPy/openpyxl 다운로드 및 12MB Excel 파싱으로 시간이 걸립니다.
4. 상태 메시지에 `준비 완료 · 380개 부문`이 표시되면 추가 기능을 테스트합니다.

## 파일

- `index.html`, `style.css`: 교수님 예시 화면에 2개 섹션 추가
- `app.js`: 원본 UI 동작 유지, Excel 초기화 직후 확장 기능 초기화 1회 호출
- `worker.js`: 원본 worker에 `extension` 메시지 1개 추가
- `model.py`: 원본 모델에 `extension_data()` 1개 추가
- `extension.js`: 추가한 실시간 차트 및 선택 UI
- `data/io-2023.xlsx`: 2023년 산업연관표 기본부문 Excel
- `.nojekyll`: GitHub Pages Jekyll 처리 우회

## 주의사항

최초 로딩은 네트워크 상태에 따라 오래 걸릴 수 있습니다. GitHub Pages 등 HTTP(S) 환경에서 실행해야 합니다. 로컬에서 파일을 직접 더블클릭하면 `fetch`가 차단될 수 있습니다. 계산은 원본의 검증 조건을 충족해야 진행됩니다.
