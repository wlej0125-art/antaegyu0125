2. 국내 생산물 최종수요 증가 시뮬레이션

수입 완제품 구매를 제외한 국내 생산물 최종수요 증가를 입력하세요. 여러 산업의 증가액은 합산됩니다.

1,000백만원 = 10억원. 이번 버전은 양의 수요 증가만 지원합니다.

    시나리오를 추가하세요.

    생산유발액 상위 15개 산업

    산업별 유발액 — 백만원, 생산유발액 내림차순
    코드산업생산수입부가가치

    3. 산업별 투자 효율 비교 추가 기능

    3개 산업을 선택하고 국내 생산물의 최종수요 증가액을 슬라이더로 조절하세요. 그래프가 즉시 바뀝니다.

    단위: 억원 (1억원 = 100백만원). 이 분석은 실제 투자 수익률이 아닌 산업연관표 기반 생산·부가가치·수입 유발효과를 비교합니다.

    4. 산업 간 전후방 연관효과 추가 기능

    영향력계수(후방연관)와 감응도계수(전방연관)를 확인하고, 해당 산업의 최종수요 증가가 다른 산업에 미치는 생산 파급효과를 실시간으로 확인합니다.

    영향력계수와 감응도계수는 고정된 산업구조의 특성이므로 투자액을 바꿔도 변하지 않습니다. 대신 산업별 생산유발액은 투자액에 비례해 변합니다.

    후방연관: 중간투입 구조 상위 10개

    전방연관: 중간재 공급 구조 상위 10개

    선택 산업의 최종수요 증가에 따른 생산유발액 상위 12개
